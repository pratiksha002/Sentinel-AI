## 📞 How to Get Help

**Stuck on Concept** (don't understand formation control, distributed algorithms, etc):
- Re-read relevant section of `research_and_study_plan.md`
- Search for different explanation on YouTube
- Ask your team to explain it
- Post question on robotics forums (robotics.stackexchange.com)

**Stuck on Tool** (ROS 2 won't compile, PX4 won't build):
- Check `resource_library_and_reference.md` Section 4 (Troubleshooting)
- Check official documentation (docs.ros.org, docs.px4.io)
- Search GitHub issues for similar problem
- Post detailed question to relevant forum (discourse.ros.org, px4.io/forum)

**Stuck on Code** (algorithm doesn't work, drones crash):
- Check if problem exists in simulation first
- Log everything (rosbag, PX4 logs)
- Compare against code templates in `resource_library_and_reference.md`
- Simplify problem (single drone, basic movement)
- Ask team or mentors for second opinion

**Stuck on Progress** (weeks slipping, falling behind):
- Reference `advanced_topics_and_execution_details.md` Part 6 (Timeline Adjustments)
- Identify what's blocking progress
- Adjust timeline or scope if needed
- Ask for help (you don't have to solve this solo)
